# Circular Tracks

Given
● Circular tracks, 5 in total. From Track 1 to Track 5.
Track 1 - Innermost track
Track 5 - Outermost track
● Each track is associated with specific value range
○ Track 1: 0 - 20
○ Track 2: 20 - 40

○ Track 3: 40 - 60
○ Track 4: 60 - 80
○ Track 5: 80 - 100
● Triangle shapes are the values to be plotted on tracks as per
described in Problem statement section
Problem Statement

1. There should be a total of 20 triangles plotted on track.
2. Each triangle should pick random values from 0 - 100 and to
   be plotted in respective tracks as per the value range.
   For eg: If value picked by triangle is 45, it should be plotted
   on “Track 3”
3. Each time a user reloads the page a fresh rendering should
   happen.
4. Triangles should be plotted in a way that it shouldn’t be
   overlapped.
